
# Foodie

Foodie is a food delivery platform inspired by Zomato and Swiggy.

## Project Goals

Build a scalable food delivery application while learning real-world backend engineering and system design.

## Technology Stack

- Frontend: React.js
- Backend: Python, FastAPI
- Database: PostgreSQL
- Cache: Redis
- Message Broker: RabbitMQ
- Version Control: Git and GitHub

## Current Status

Project initialization and environment setup.
